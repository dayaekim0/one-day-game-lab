ONE DAY GAME LAB - 배포 방법

1. 이 ZIP 파일의 압축을 풉니다.
2. Netlify Drop (https://app.netlify.com/drop)에 압축 푼 game_lab 폴더 전체를 드래그합니다.
3. 발급된 netlify.app 주소를 열어 게임이 실행되는지 확인합니다.
4. 그 주소를 인스타그램 프로필에 추가합니다.

DAY 01 회사 탈출 게임은 기존 chatgpt.site로 이동하는 외부 링크입니다.
DAY 02~06 게임은 이 폴더의 HTML 파일에서 실행됩니다.
DAY 02~05는 원본 미확보로 재구성된 버전입니다.
