# 퇴사 파이프라인 — 월 1,000만 원 데일리 체크리스트

2027년 12월 31일 퇴사를 목표로, 공구·협찬·제휴 수익 파이프라인을 매일 15분씩 굴리는 모바일 퍼스트 웹앱.

- **D-day 카운터**: 2027.12.31까지 남은 일·주·개월, 시작일 대비 진행률
- **1,000만 원 포트폴리오**: 공구 700 / 협찬 200 / 제휴 100 (만원), 월별 실적 입력, 최근 6개월 추이
- **하루 15분 루틴**: 날짜별 체크, 진행 분, 연속 달성 스트릭, 최근 7일 기록, 항목 편집
- **주간 미션**: 월요일 시작 주차별 체크, 지난 주 조회, 최근 4주 달성률, 항목 편집
- **로컬 저장**: 모든 데이터는 브라우저 LocalStorage(`retire-pipeline:v1`)에 저장, JSON 백업 내보내기/불러오기, 초기화

## 실행

```bash
cd retire-pipeline
npm install
npm run dev     # http://localhost:3000
npm run build    # 정적 파일이 out/ 에 생성됨 (어느 경로에 올려도 동작)
```

스택: Next.js 14 (App Router) · Tailwind CSS · Lucide React · TypeScript

목표 금액·퇴사일·기본 루틴/미션은 `lib/constants.ts`에서 바꿀 수 있어요.
