# 실제 데이터 입력 체크리스트

> `npm run data:missing -- --write`로 자동 생성됩니다. 아는 것만 적어 주세요. 모르는 칸은 비워 두면 계속 "미입력"으로 표시돼요.
> 편의시설: 있음 / 없음 / 모름 · 편의성: 좋음 / 보통 / 불편 · 추천도: 1~5

## 여행: 삿포로·오타루 4박 5일 (2026-10-05 ~ 2026-10-09)

### 여행 전체
- [ ] 한 줄 소개 (예: 첫 해외여행, 료칸 위주 등)
- [ ] 일본 오타루 2박 숙소가 어디였나요?
- [ ] 일본 삿포로 2박 숙소가 어디였나요?
- [ ] (선택) 개별 결제 건: 날짜 / 가게 / 금액
- [ ] (선택) 다음에 같은 여행을 간다면 예상 비용 (항목별)
- [ ] 대표 사진 1장
